#A quoi servent-ils ? (quelques applications possibles)

Les workflows peuvent être utilisés dans plusieurs situations. 

- Exécuter des tests unitaires ou d'intégration
- Déployer automatiquement une application sur un serveur ou dans le cloud
- Générer de la documentation
- Publier des packages ou de nouvelles versions
- Envoyer des notifications
- Automatiser des tâches administratives comme la gestion des issues ou des pull requests
