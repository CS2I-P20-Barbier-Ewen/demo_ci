# Comment fonctionnent-ils ?

### Construction & architecture 

Un workflow est mis en place grace à la création de pages markdown (.md) dans le dossier /docs 

Une fois la page créée, il faut mettre la déclarer les les pages dans le fichier .git\COMMIT_EDITMSG

voici la syntaxe pour déclarer la page :

```
#   new file:   docs/github.md
```
